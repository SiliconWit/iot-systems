The Wi-Fi router restarts at night. In the morning half of the sensors are silent, because their firmware tried to connect once and stopped, and every chart has a hole. Sending a reading is the easy part of device firmware. The hard part is what the device does when the network is gone. In this lesson you write MQTT client firmware for three boards (ESP32, RPi Pico W, and STM32 with an ESP-01 Wi-Fi module). All three use the same topic names and message format, reconnect in a controlled way, and keep readings while offline. #MQTT #ESP32 #MultiPlatform

The three nodes publish under one tree of topic names.

```text
  factory/
  └── warehouse-a/
      ├── esp32/
      │   └── esp32-001/
      │       ├── telemetry   ◄── readings
      │       ├── alerts      ◄── limit passed
      │       ├── commands    ──► to the device
      │       └── status      ◄── online / offline
      ├── pico/
      │   └── pico-001/ ...
      └── stm32/
          └── stm32-001/ ...

  Subscribe: factory/warehouse-a/+/+/telemetry
  gives the readings of all three devices.
```

## Topic Hierarchy Design

<InArticleAd />


A flat topic like `sensor/data` works for one device. With ten you cannot tell them apart, and with a hundred you cannot give each its own permissions. Levels let you select and protect any part of the system.

### The Hierarchy Pattern

This course uses five levels:

```
site/building/device_type/device_id/measurement
```

For a concrete deployment:

```
factory/warehouse-a/esp32/esp32-001/telemetry
factory/warehouse-a/esp32/esp32-001/alerts
factory/warehouse-a/esp32/esp32-001/commands
factory/warehouse-a/pico/pico-001/telemetry
factory/warehouse-a/stm32/stm32-001/telemetry
factory/office/esp32/esp32-002/telemetry
```

### Why Hierarchy Matters

**Permissions.** With the access control list (ACL) from [the secure broker setup](/education/iot-systems/mqtt-broker-setup-secure-connection/), each device is limited to its own branch. Device `esp32-001` can publish to `factory/warehouse-a/esp32/esp32-001/#` and nowhere else. A dashboard user can subscribe to `factory/warehouse-a/#` and sees the warehouse but not the office.

**Wildcards.** A subscriber can replace levels with two characters. `+` stands for exactly one level: `factory/+/esp32/+/telemetry` gives the ESP32 telemetry of all buildings. `#` stands for all levels that follow and must be last: `factory/warehouse-a/#` gives everything in the warehouse. A `+` never stands for two levels or for none, so a device that leaves out one level is invisible to every subscription that counts the levels.

### SiliconWit.io Topic Mapping

The SiliconWit.io platform uses its own, shorter pattern with the device in the middle:

```
d/{device_id}/t
```

`{device_id}` is the device identifier from your SiliconWit.io dashboard, and `t` stands for telemetry. Commands arrive on `d/{device_id}/c`. The device ID is the username and a device access token is the password.

## JSON Payload Standard

<InArticleAd />


If each board names its fields differently, every program that reads the data needs three versions. So all devices in this course publish the same JSON fields.

### Telemetry Payload

```json title="telemetry_payload.json"
{
  "device_id": "esp32-001",
  "ts": 1710028800,
  "temperature": 25.3,
  "humidity": 60.1
}
```

| Field | Type | Description |
|-------|------|-------------|
| `device_id` | string | Unique identifier matching the topic hierarchy |
| `ts` | integer | Unix epoch timestamp (seconds since 1970-01-01) |
| `temperature` | float | Temperature in degrees Celsius |
| `humidity` | float | Relative humidity percentage |

### Alert Payload

```json title="alert_payload.json"
{
  "device_id": "esp32-001",
  "ts": 1710028800,
  "alert": "temperature_high",
  "value": 45.2,
  "threshold": 40.0
}
```

### Command Payload

```json title="command_payload.json"
{
  "command": "set_interval",
  "value": 30
}
```

The device receives a command on its `commands` subtopic. A command is a request: the device keeps its own limits and refuses a value outside them, because a command can arrive late, twice or not at all.

### Why JSON and Not Binary?

JSON repeats the field names in every message. At one message every 10 seconds those bytes are small beside the TCP and TLS overhead, and a person can read the message and every tool accepts it. For hundreds of messages per second, look at a binary format such as CBOR.

## QoS Selection Strategy

<InArticleAd />


MQTT has three quality of service (QoS) levels. A higher level costs more packets, so each kind of message gets the level it needs.

| QoS | What it promises | Use in this course |
|-----|-----------|-------------------|
| 0 | At most once, no confirmation | Telemetry every 10 s. A lost reading is replaced by the next one. |
| 1 | At least once, confirmed by the broker | Alerts. The device knows that the broker has the alert. A repeat does no harm. |
| 2 | Exactly once (four packets) | Commands, where a repeat could change the result. |

No level promises that a message reached its final reader. A confirmed alert is in the broker. Whether a person saw it is a different question, which the alert system must answer.

:::tip[QoS applies to each direction independently]
QoS is set per publish and per subscription. A device can publish telemetry at QoS 0 and subscribe to commands at QoS 2 on the same connection.
:::

### Wi-Fi Connection

This file joins the Wi-Fi network and tries again up to 10 times if the connection drops. After the tenth quick failure it stops for good: a router off for a few minutes leaves the node offline until it restarts. On a site, use the growing waits of [the ESP32 Wi-Fi lesson](/education/embedded-programming-esp32/wifi-network-configuration/).

```c title="wifi_connect.c"
#include <string.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "freertos/event_groups.h"
#include "esp_wifi.h"
#include "esp_log.h"
#include "esp_event.h"
#include "nvs_flash.h"

#define WIFI_SSID      CONFIG_WIFI_SSID
#define WIFI_PASS      CONFIG_WIFI_PASSWORD
#define MAX_RETRY      10

static const char *TAG = "wifi";
static EventGroupHandle_t wifi_event_group;
static const int CONNECTED_BIT = BIT0;
static int retry_count = 0;

static void wifi_event_handler(void *arg, esp_event_base_t event_base,
                               int32_t event_id, void *event_data)
{
    if (event_base == WIFI_EVENT && event_id == WIFI_EVENT_STA_START) {
        esp_wifi_connect();
    } else if (event_base == WIFI_EVENT && event_id == WIFI_EVENT_STA_DISCONNECTED) {
        if (retry_count < MAX_RETRY) {
            esp_wifi_connect();
            retry_count++;
            ESP_LOGI(TAG, "Retrying Wi-Fi connection (%d/%d)", retry_count, MAX_RETRY);
        } else {
            ESP_LOGE(TAG, "Wi-Fi connection failed after %d retries", MAX_RETRY);
        }
    } else if (event_base == IP_EVENT && event_id == IP_EVENT_STA_GOT_IP) {
        ip_event_got_ip_t *event = (ip_event_got_ip_t *)event_data;
        ESP_LOGI(TAG, "Got IP: " IPSTR, IP2STR(&event->ip_info.ip));
        retry_count = 0;
        xEventGroupSetBits(wifi_event_group, CONNECTED_BIT);
    }
}

void wifi_init_sta(void)
{
    wifi_event_group = xEventGroupCreate();

    ESP_ERROR_CHECK(esp_netif_init());
    ESP_ERROR_CHECK(esp_event_loop_create_default());
    esp_netif_create_default_wifi_sta();

    wifi_init_config_t cfg = WIFI_INIT_CONFIG_DEFAULT();
    ESP_ERROR_CHECK(esp_wifi_init(&cfg));

    esp_event_handler_instance_t instance_any_id;
    esp_event_handler_instance_t instance_got_ip;
    ESP_ERROR_CHECK(esp_event_handler_instance_register(
        WIFI_EVENT, ESP_EVENT_ANY_ID, &wifi_event_handler, NULL, &instance_any_id));
    ESP_ERROR_CHECK(esp_event_handler_instance_register(
        IP_EVENT, IP_EVENT_STA_GOT_IP, &wifi_event_handler, NULL, &instance_got_ip));

    wifi_config_t wifi_config = {
        .sta = {
            .ssid = WIFI_SSID,
            .password = WIFI_PASS,
            .threshold.authmode = WIFI_AUTH_WPA2_PSK,
        },
    };
    ESP_ERROR_CHECK(esp_wifi_set_mode(WIFI_MODE_STA));
    ESP_ERROR_CHECK(esp_wifi_set_config(WIFI_IF_STA, &wifi_config));
    ESP_ERROR_CHECK(esp_wifi_start());

    ESP_LOGI(TAG, "Waiting for Wi-Fi connection...");
    xEventGroupWaitBits(wifi_event_group, CONNECTED_BIT, pdFALSE, pdTRUE, portMAX_DELAY);
    ESP_LOGI(TAG, "Wi-Fi connected");
}
```

### MQTT Handler with TLS, LWT, and Reconnection

Read this file in three parts:

- `mqtt_event_handler` reacts to events. On connect it publishes a retained "online" status and subscribes to commands. On disconnect it only notes when to try again, after a growing delay: it runs inside the MQTT client's own task, and a wait there would stop the client. `mqtt_reconnect_if_due()` (declare it in `mqtt_handler.h`) starts the attempt from the sensor task.
- `mqtt_app_start` sets the broker address, the CA certificate, the last will (LWT, the "offline" message the broker publishes if the device disappears) and a keepalive of 30 seconds.
- The publish functions use QoS 0 for telemetry and QoS 1 for alerts.

```c title="mqtt_handler.c"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"
#include "esp_random.h"
#include "esp_timer.h"
#include "mqtt_client.h"
#include "mqtt_handler.h"

static const char *TAG = "mqtt";
static esp_mqtt_client_handle_t client = NULL;
static bool mqtt_connected = false;
extern int publish_interval_s;          /* defined in main.c */

/* Reconnection state */
static int64_t next_attempt_us = 0;     /* 0: no attempt waiting */
static int backoff_ms = 1000;
static const int BACKOFF_MAX_MS = 60000;
static const float BACKOFF_MULTIPLIER = 2.0;

/* Embedded CA certificate for TLS (load from certs/ca_cert.pem) */
extern const uint8_t ca_cert_pem_start[] asm("_binary_ca_cert_pem_start");
extern const uint8_t ca_cert_pem_end[]   asm("_binary_ca_cert_pem_end");

/* Topic definitions */
#define DEVICE_ID       "esp32-001"
#define TOPIC_TELEMETRY "factory/warehouse-a/esp32/" DEVICE_ID "/telemetry"
#define TOPIC_ALERTS    "factory/warehouse-a/esp32/" DEVICE_ID "/alerts"
#define TOPIC_COMMANDS  "factory/warehouse-a/esp32/" DEVICE_ID "/commands"
#define TOPIC_STATUS    "factory/warehouse-a/esp32/" DEVICE_ID "/status"

/* Last Will and Testament message */
#define LWT_MESSAGE     "{\"device_id\":\"" DEVICE_ID "\",\"status\":\"offline\"}"

static void mqtt_event_handler(void *handler_args, esp_event_base_t base,
                               int32_t event_id, void *event_data)
{
    esp_mqtt_event_handle_t event = event_data;

    switch ((esp_mqtt_event_id_t)event_id) {
    case MQTT_EVENT_CONNECTED:
        ESP_LOGI(TAG, "MQTT connected to broker");
        mqtt_connected = true;
        backoff_ms = 1000;  /* Reset backoff on successful connection */

        /* Publish online status (retained so new subscribers see it immediately) */
        esp_mqtt_client_publish(client, TOPIC_STATUS,
            "{\"device_id\":\"" DEVICE_ID "\",\"status\":\"online\"}", 0, 1, 1);

        /* Subscribe to command topic at QoS 2 */
        esp_mqtt_client_subscribe(client, TOPIC_COMMANDS, 2);
        ESP_LOGI(TAG, "Subscribed to %s at QoS 2", TOPIC_COMMANDS);
        break;

    case MQTT_EVENT_DISCONNECTED: {
        ESP_LOGW(TAG, "MQTT disconnected");
        mqtt_connected = false;

        /* Add jitter: random offset of 0 to 25% of backoff */
        int jitter = (esp_random() % (backoff_ms / 4 + 1));
        int delay = backoff_ms + jitter;
        ESP_LOGI(TAG, "Reconnecting in %d ms (backoff: %d, jitter: %d)",
                 delay, backoff_ms, jitter);

        /* Do not wait here: this handler runs in the MQTT task, and a
         * wait would stop that task. Note the time instead; the sensor
         * task calls mqtt_reconnect_if_due(), which starts the attempt. */
        next_attempt_us = esp_timer_get_time() + (int64_t)delay * 1000;

        /* Increase backoff for next attempt */
        backoff_ms = (int)(backoff_ms * BACKOFF_MULTIPLIER);
        if (backoff_ms > BACKOFF_MAX_MS) {
            backoff_ms = BACKOFF_MAX_MS;
        }
        break;
    }

    case MQTT_EVENT_DATA: {
        ESP_LOGI(TAG, "Received message on topic: %.*s", event->topic_len, event->topic);
        ESP_LOGI(TAG, "Payload: %.*s", event->data_len, event->data);

        /* event->data is NOT null-terminated: copy it before using strstr */
        char cmd[128];
        int cmd_len = event->data_len;
        if (cmd_len > (int)sizeof(cmd) - 1) {
            cmd_len = sizeof(cmd) - 1;
        }
        memcpy(cmd, event->data, cmd_len);
        cmd[cmd_len] = '\0';

        /* Parse command JSON (simplified; production code should use cJSON) */
        if (strstr(cmd, "set_interval")) {
            int new_interval = 0;
            const char *value = strstr(cmd, "\"value\"");
            if (value && (value = strchr(value, ':')) != NULL) {
                new_interval = atoi(value + 1);
            }
            /* A command is a request: keep the device's own limits */
            if (new_interval >= 5 && new_interval <= 3600) {
                publish_interval_s = new_interval;
                ESP_LOGI(TAG, "Publish interval set to %d seconds", new_interval);
            } else {
                ESP_LOGW(TAG, "Refused interval %d (allowed 5 to 3600 s)", new_interval);
            }
        }
        break;
    }

    case MQTT_EVENT_ERROR:
        ESP_LOGE(TAG, "MQTT error type: %d", event->error_handle->error_type);
        break;

    default:
        break;
    }
}

void mqtt_app_start(void)
{
    esp_mqtt_client_config_t mqtt_cfg = {
        .broker = {
            .address = {
                .uri = "mqtts://your-broker-ip:8883",
            },
            .verification = {
                .certificate = (const char *)ca_cert_pem_start,
            },
        },
        .credentials = {
            .username = "esp32-001",
            .authentication = {
                .password = "your-device-password",
            },
            .client_id = DEVICE_ID,
        },
        .session = {
            .last_will = {
                .topic = TOPIC_STATUS,
                .msg = LWT_MESSAGE,
                .msg_len = strlen(LWT_MESSAGE),
                .qos = 1,
                .retain = 1,
            },
            .keepalive = 30,
        },
        .network = {
            /* The growing waits below replace the fixed 10 s retry */
            .disable_auto_reconnect = true,
        },
    };

    client = esp_mqtt_client_init(&mqtt_cfg);
    esp_mqtt_client_register_event(client, ESP_EVENT_ANY_ID, mqtt_event_handler, NULL);
    esp_mqtt_client_start(client);
}

/* Called from the sensor task, never from the event handler */
void mqtt_reconnect_if_due(void)
{
    if (!mqtt_connected && next_attempt_us != 0 &&
        esp_timer_get_time() >= next_attempt_us) {
        next_attempt_us = 0;
        esp_mqtt_client_reconnect(client);
    }
}

bool mqtt_is_connected(void)
{
    return mqtt_connected;
}

void mqtt_publish_telemetry(float temperature, float humidity)
{
    if (!mqtt_connected) {
        ESP_LOGW(TAG, "Not connected, buffering telemetry");
        /* Buffer logic covered in the offline buffering section below */
        return;
    }

    time_t now;
    time(&now);

    /* Until SNTP has set the clock, time() counts from 1970 at power-on:
     * send null ("not known"), not a false date */
    char ts[16] = "null";
    if (now > 1700000000) {
        snprintf(ts, sizeof(ts), "%ld", (long)now);
    }

    char payload[256];
    snprintf(payload, sizeof(payload),
        "{\"device_id\":\"%s\",\"ts\":%s,\"temperature\":%.1f,\"humidity\":%.1f}",
        DEVICE_ID, ts, temperature, humidity);

    /* QoS 0 for regular telemetry */
    esp_mqtt_client_publish(client, TOPIC_TELEMETRY, payload, 0, 0, 0);
    ESP_LOGI(TAG, "Published: %s", payload);
}

void mqtt_publish_alert(const char *alert_type, float value, float threshold)
{
    if (!mqtt_connected) {
        return;
    }

    time_t now;
    time(&now);

    char payload[256];
    snprintf(payload, sizeof(payload),
        "{\"device_id\":\"%s\",\"ts\":%ld,\"alert\":\"%s\",\"value\":%.1f,\"threshold\":%.1f}",
        DEVICE_ID, (long)now, alert_type, value, threshold);

    /* QoS 1 for alerts (at least once delivery) */
    esp_mqtt_client_publish(client, TOPIC_ALERTS, payload, 0, 1, 0);
    ESP_LOGW(TAG, "Alert published: %s", payload);
}
```

```c title="mqtt_handler_siliconwit.c (config section)"
/* SiliconWit.io connection configuration */
#define SILICONWIT_DEVICE_ID    "your-device-id"     /* From SiliconWit.io dashboard */

        .client_id = SILICONWIT_DEVICE_ID,
    },
    .session = {
        .keepalive = 30,
    },
};

/* Publish to the SiliconWit.io topic */
esp_mqtt_client_publish(client, SILICONWIT_TOPIC, payload, 0, 0, 0);
```

### Main Application Loop

`sensor_task` reads the sensor, publishes and waits. Notice that the comparison with the 40 °C limit happens here, in the device. The alert message only reports it.

```c title="main.c"
#include <stdio.h>
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "esp_log.h"
#include "nvs_flash.h"
#include "esp_netif_sntp.h"
#include "wifi_connect.h"
#include "mqtt_handler.h"
#include "bme280.h"

static const char *TAG = "main";
int publish_interval_s = 10;   /* not static: a command can change it */

#define TEMP_ALERT_THRESHOLD 40.0

void sensor_task(void *pvParameters)
{
    bme280_init();

    while (1) {
        float temperature = bme280_read_temperature();
        float humidity = bme280_read_humidity();

        ESP_LOGI(TAG, "BME280: temp=%.1f C, hum=%.1f %%", temperature, humidity);

        mqtt_publish_telemetry(temperature, humidity);

        /* Check alert conditions */
        if (temperature > TEMP_ALERT_THRESHOLD) {
            mqtt_publish_alert("temperature_high", temperature, TEMP_ALERT_THRESHOLD);
        }

        /* Wait in 1 s steps, so a reconnection waits no longer than planned */
        for (int s = 0; s < publish_interval_s; s++) {
            vTaskDelay(pdMS_TO_TICKS(1000));
            mqtt_reconnect_if_due();
        }
    }
}

void app_main(void)
{
    ESP_ERROR_CHECK(nvs_flash_init());

    wifi_init_sta();

    /* Set the clock from the internet (ESP-IDF 5.1 or later) */
    esp_sntp_config_t sntp_cfg = ESP_NETIF_SNTP_DEFAULT_CONFIG("pool.ntp.org");
    esp_netif_sntp_init(&sntp_cfg);
    if (esp_netif_sntp_sync_wait(pdMS_TO_TICKS(10000)) != ESP_OK) {
        ESP_LOGW(TAG, "Clock not set yet: ts is sent as null until it is");
    }

    mqtt_app_start();

    xTaskCreate(sensor_task, "sensor_task", 4096, NULL, 5, NULL);
}
```

### Configuration

All settings are in one file, so the other files contain no names or passwords.

```python title="config.py"
# Wi-Fi settings
WIFI_SSID = "your-wifi-ssid"
WIFI_PASSWORD = "your-wifi-password"

# MQTT broker settings (self-hosted Mosquitto)
MQTT_BROKER = "your-broker-ip"
MQTT_PORT = 1883
MQTT_USER = "pico-001"
MQTT_PASSWORD = "your-device-password"
```

### MQTT Client with Reconnection

One class holds the whole client. Notice `connect`, which sets the last will before it connects, and `reconnect`, which waits for the backoff delay and then calls `connect` again.

```python title="mqtt_client.py"
import time
import json
import machine
from umqtt.simple import MQTTClient
import config

class SensorMQTTClient:
    def __init__(self):
        self.client = None
        self.connected = False
        self.backoff_ms = config.BACKOFF_INITIAL_MS
        self.publish_interval = config.PUBLISH_INTERVAL_S

    def connect(self):
        """Connect to the MQTT broker with LWT."""
        lwt_payload = json.dumps({
            "device_id": config.DEVICE_ID,
            "status": "offline"
        })

        self.client = MQTTClient(
            client_id=config.DEVICE_ID,
            server=config.MQTT_BROKER,
            port=config.MQTT_PORT,
            user=config.MQTT_USER,
            password=config.MQTT_PASSWORD,
            keepalive=30
        )

        # Set Last Will and Testament
        self.client.set_last_will(
            config.TOPIC_STATUS,
            lwt_payload,
            retain=True,
            qos=1
        )

        # Set callback for incoming messages
        self.client.set_callback(self._on_message)

        try:
            self.client.connect()
            self.connected = True
            self.backoff_ms = config.BACKOFF_INITIAL_MS
            print(f"MQTT connected to {config.MQTT_BROKER}")

            # Publish online status (retained)
            online_payload = json.dumps({
                "device_id": config.DEVICE_ID,
                "status": "online"
            })
            self.client.publish(config.TOPIC_STATUS, online_payload, retain=True, qos=1)

            # Subscribe to commands
            self.client.subscribe(config.TOPIC_COMMANDS, qos=1)
            print(f"Subscribed to {config.TOPIC_COMMANDS}")

        except OSError as e:
            print(f"MQTT connection failed: {e}")
            self.connected = False

    def reconnect(self):
        """Reconnect with exponential backoff and jitter."""
        import urandom
        jitter = urandom.getrandbits(16) % (self.backoff_ms // 4 + 1)
        delay = self.backoff_ms + jitter
        print(f"Reconnecting in {delay} ms")
        time.sleep_ms(delay)

        self.backoff_ms = int(self.backoff_ms * config.BACKOFF_MULTIPLIER)
        if self.backoff_ms > config.BACKOFF_MAX_MS:
            self.backoff_ms = config.BACKOFF_MAX_MS

        self.connect()

    def _on_message(self, topic, msg):
        """Handle incoming MQTT messages."""
        topic_str = topic.decode("utf-8")
        msg_str = msg.decode("utf-8")
        print(f"Received on {topic_str}: {msg_str}")

        try:
            data = json.loads(msg_str)
            if data.get("command") == "set_interval":
                value = data.get("value")
                # A command is a request: accept a whole number in range only
                if isinstance(value, int) and 5 <= value <= 3600:
                    self.publish_interval = value
                    print(f"Publish interval set to {self.publish_interval}s")
                else:
                    print("Refused interval:", value)
            elif data.get("command") == "reboot":
                print("Reboot command received, resetting...")
                time.sleep(1)
                machine.reset()
        except ValueError:
            print("Failed to parse command JSON")

    def check_messages(self):
        """Non-blocking check for incoming messages."""
        if self.connected:
            try:
                self.client.check_msg()
            except OSError:
                self.connected = False

    def ping(self):
        """umqtt.simple sends no keepalive pings by itself."""
        if self.connected:
            try:
                self.client.ping()
            except OSError:
                self.connected = False

    def publish_telemetry(self, temperature, humidity):
        """Publish sensor data as JSON at QoS 0."""
        if not self.connected:
            print("Not connected, cannot publish")
            return False

        payload = json.dumps({
            "device_id": config.DEVICE_ID,
            "ts": int(time.time()),
            "temperature": round(temperature, 1),
            "humidity": round(humidity, 1)
        })

        try:
            self.client.publish(config.TOPIC_TELEMETRY, payload, qos=0)
            print(f"Published telemetry: {payload}")
            return True
        except OSError as e:
            print(f"Publish failed: {e}")
            self.connected = False
            return False

    def publish_alert(self, alert_type, value, threshold):
        """Publish alert at QoS 1."""
        if not self.connected:
            return False

        payload = json.dumps({
            "device_id": config.DEVICE_ID,
            "ts": int(time.time()),
            "alert": alert_type,
            "value": round(value, 1),
            "threshold": round(threshold, 1)
        })

        try:
            self.client.publish(config.TOPIC_ALERTS, payload, qos=1)
            print(f"Alert published: {payload}")
            return True
        except OSError:
            self.connected = False
            return False

    def disconnect(self):
        """Graceful disconnect."""
        if self.client and self.connected:
            self.client.disconnect()
            self.connected = False
```

### Wi-Fi Connection and Main Loop

If the client is connected, the loop first sends the stored readings and then the new one. If not, it stores the reading and tries to reconnect. The call to `reconnect` waits for the whole backoff delay, so during a long outage the stored readings are further apart than 10 seconds.

```python title="main.py"
import network
import time
import json
import config
from bme280 import BME280
from mqtt_client import SensorMQTTClient
from offline_buffer import OfflineBuffer
from machine import Pin, I2C

def connect_wifi():
    """Connect to Wi-Fi and wait for an IP address."""
    wlan = network.WLAN(network.STA_IF)
    wlan.active(True)
    wlan.connect(config.WIFI_SSID, config.WIFI_PASSWORD)

    max_wait = 20
    while max_wait > 0:
        if wlan.isconnected():
            break
        max_wait -= 1
        print("Waiting for Wi-Fi...")
        time.sleep(1)

    if not wlan.isconnected():
        raise RuntimeError("Wi-Fi connection failed")

    ip = wlan.ifconfig()[0]
    print(f"Wi-Fi connected, IP: {ip}")
    return wlan

def main():
    wlan = connect_wifi()

    # Set the clock (UTC). Without it the Pico's clock starts at
    # 2021-01-01 and every "ts" is a believable but false date.
    import ntptime
    try:
        ntptime.settime()
    except OSError:
        print("NTP failed: ts values are wrong until the clock is set")

    # Initialize I2C and BME280
    i2c = I2C(0, sda=Pin(0), scl=Pin(1), freq=400000)
    sensor = BME280(i2c=i2c)

    # Initialize MQTT client and offline buffer
    mqtt = SensorMQTTClient()
    buffer = OfflineBuffer(max_entries=50)

    mqtt.connect()

    while True:
        # Check for incoming commands
        mqtt.check_messages()

        # Read sensor
        temperature = sensor.temperature()
        humidity = sensor.humidity()
        print(f"BME280: temp={temperature:.1f} C, hum={humidity:.1f} %")

        if mqtt.connected:
            # Flush any buffered readings first
            buffer.flush(mqtt)

            # Publish current reading
            mqtt.publish_telemetry(temperature, humidity)

            # Check alert conditions
            if temperature > config.TEMP_ALERT_THRESHOLD:
                mqtt.publish_alert("temperature_high", temperature,
                                   config.TEMP_ALERT_THRESHOLD)
        else:
            # Buffer the reading for later
            buffer.store(temperature, humidity)
            mqtt.reconnect()

        # Wait in 1 s steps: commands are read at once, and a ping every
        # 15 s keeps the 30 s keepalive even when the interval is longer
        for s in range(mqtt.publish_interval):
            time.sleep(1)
            mqtt.check_messages()
            if s % 15 == 14:
                mqtt.ping()

if __name__ == "__main__":
    main()
```

## STM32 MQTT Client (via ESP-01 AT Commands)

<InArticleAd />


The STM32F4 has no Wi-Fi, so an ESP-01 module is connected to it over a UART serial line. The ESP-01 does the Wi-Fi and TCP work. The STM32 controls it with AT commands, short text commands that begin with the letters AT, and then builds each MQTT packet itself, byte by byte.

This division is common in industry: the main microcontroller does the real-time control, and a second module does the communication. If the network fails, the control continues, but only if it runs apart from the network code: the listing below is one loop that waits up to 15 s for Wi-Fi and up to 75 s between attempts, so real control belongs in a timer interrupt or its own RTOS task.

### Hardware Connections

| STM32 Pin | ESP-01 Pin | Notes |
|-----------|------------|-------|
| PA2 (USART2 TX) | RX | 3.3V logic, no level shifter needed |
| PA3 (USART2 RX) | TX | 3.3V logic |
| 3.3V | VCC, CH_PD | ESP-01 needs 3.3V (not 5V) |
| GND | GND | Common ground |

:::caution[ESP-01 power supply]
The ESP-01 draws up to 300 mA during Wi-Fi transmission. The STM32 dev board 3.3V regulator may not supply enough current. Use a separate 3.3V regulator (AMS1117-3.3 or similar) powered from 5V for reliable operation.
:::

### AT Command Sequence

The sequence has two parts. A line with `->` is the answer of the ESP-01. First the module joins the Wi-Fi network:

```text title="at_command_sequence.txt"
# 1. Test AT communication
AT
-> OK

# 2. Set Wi-Fi mode to Station
AT+CWMODE=1
-> OK

# 3. Connect to Wi-Fi access point
AT+CWJAP="your-ssid","your-password"
-> WIFI CONNECTED
-> WIFI GOT IP
-> OK

# 4. Check IP address
AT+CIFSR
-> +CIFSR:STAIP,"192.168.1.100"
-> OK
```

Then it opens the TCP connection to the broker. After step 7 the module is "transparent": every byte the STM32 sends goes straight to the broker.

```text title="at_command_sequence.txt (continued)"
# 5. Establish TCP connection to MQTT broker
AT+CIPSTART="TCP","your-broker-ip",1883
-> CONNECT
-> OK

# 6. Set transparent transmission mode
AT+CIPMODE=1
-> OK

# 7. Start sending data
AT+CIPSEND
-> >

# (Now send raw MQTT CONNECT packet bytes)
# (Then MQTT PUBLISH, SUBSCRIBE, etc.)
```

### STM32 AT Command Driver

The driver sends the AT commands above from C. Notice that each command waits for its answer with a time limit, so a silent module cannot stop the program for ever.

```c title="esp01_at.h"

#define ESP01_AT_H

#include <stdint.h>

    AT_OK,
    AT_ERROR,
    AT_TIMEOUT
} at_result_t;

void     esp01_init(void);

at_result_t esp01_tcp_connect(const char *host, uint16_t port);
void     esp01_send_raw(const uint8_t *data, uint16_t len);
uint16_t esp01_recv_raw(uint8_t *buf, uint16_t max_len, uint32_t timeout_ms);

#endif
```

```c title="esp01_at.c"
#include "esp01_at.h"
#include "stm32f4xx_hal.h"
#include <string.h>
#include <stdio.h>

extern UART_HandleTypeDef huart2;

static char rx_buffer[512];
static volatile uint16_t rx_index = 0;
static uint8_t rx_byte;  /* One byte, filled by the UART interrupt */

/* Empty the receive buffer with the UART interrupt held off */
static void rx_clear(void)
{
    __disable_irq();
    rx_index = 0;
    memset(rx_buffer, 0, sizeof(rx_buffer));
    __enable_irq();
}

void esp01_init(void)
{
    rx_clear();

    /* Enable UART receive interrupt (one byte at a time) */
    HAL_UART_Receive_IT(&huart2, &rx_byte, 1);
}

at_result_t esp01_send_cmd(const char *cmd, const char *expected, uint32_t timeout_ms)
{
    /* Clear receive buffer */
    rx_clear();

    /* Send command with CR+LF */
    char cmd_buf[128];
    snprintf(cmd_buf, sizeof(cmd_buf), "%s\r\n", cmd);
    HAL_UART_Transmit(&huart2, (uint8_t *)cmd_buf, strlen(cmd_buf), 1000);

    /* Wait for expected response */
    uint32_t start = HAL_GetTick();
    while ((HAL_GetTick() - start) < timeout_ms) {
        if (strstr(rx_buffer, expected) != NULL) {
            return AT_OK;
        }
        if (strstr(rx_buffer, "ERROR") != NULL) {
            return AT_ERROR;
        }
        HAL_Delay(10);
    }
    return AT_TIMEOUT;
}

at_result_t esp01_wifi_connect(const char *ssid, const char *password)
{
    at_result_t res;

    /* Test AT communication */
    res = esp01_send_cmd("AT", "OK", 2000);
    if (res != AT_OK) return res;

    /* Set station mode */
    res = esp01_send_cmd("AT+CWMODE=1", "OK", 2000);
    if (res != AT_OK) return res;

    /* Connect to Wi-Fi */
    char cmd[128];
    snprintf(cmd, sizeof(cmd), "AT+CWJAP=\"%s\",\"%s\"", ssid, password);
    res = esp01_send_cmd(cmd, "\r\nOK\r\n", 15000);

    return res;
}

at_result_t esp01_tcp_connect(const char *host, uint16_t port)
{
    char cmd[128];
    snprintf(cmd, sizeof(cmd), "AT+CIPSTART=\"TCP\",\"%s\",%u", host, port);
    at_result_t res = esp01_send_cmd(cmd, "\r\nOK\r\n", 10000);
    if (res != AT_OK) return res;

    /* Transparent transmission: from here every byte goes straight to
       the broker, and every byte from the broker comes straight back */
    res = esp01_send_cmd("AT+CIPMODE=1", "OK", 2000);
    if (res != AT_OK) return res;
    res = esp01_send_cmd("AT+CIPSEND", ">", 5000);
    if (res != AT_OK) return res;

    HAL_Delay(50);
    rx_clear();  /* Drop the AT replies so the buffer holds only MQTT bytes */
    return AT_OK;
}

void esp01_send_raw(const uint8_t *data, uint16_t len)
{
    /* Transparent mode is active, so the bytes go out unchanged */
    HAL_UART_Transmit(&huart2, (uint8_t *)data, len, 5000);
}

uint16_t esp01_recv_raw(uint8_t *buf, uint16_t max_len, uint32_t timeout_ms)
{
    uint32_t start = HAL_GetTick();
    while ((HAL_GetTick() - start) < timeout_ms && rx_index == 0) {
        HAL_Delay(10);
    }
    if (rx_index == 0) return 0;
    HAL_Delay(20);  /* Let the rest of the packet arrive */

    __disable_irq();
    uint16_t copy_len = (rx_index < max_len) ? rx_index : max_len;
    memcpy(buf, rx_buffer, copy_len);
    rx_index = 0;
    __enable_irq();
    return copy_len;
}

void esp01_close(void)
{
    /* Leave transparent mode: send "+++" with no line ending, with one
       second of silence before and after. Then AT commands work again. */
    HAL_Delay(1000);
    HAL_UART_Transmit(&huart2, (uint8_t *)"+++", 3, 1000);
    HAL_Delay(1000);
    esp01_send_cmd("AT+CIPMODE=0", "OK", 2000);
    esp01_send_cmd("AT+CIPCLOSE", "OK", 2000);
}

/* UART receive interrupt callback */
void HAL_UART_RxCpltCallback(UART_HandleTypeDef *huart)
{
    if (huart == &huart2) {
        if (rx_index < sizeof(rx_buffer) - 1) {
            rx_buffer[rx_index++] = (char)rx_byte;
        }
        /* Always re-arm the interrupt, even when the buffer is full */
        HAL_UART_Receive_IT(&huart2, &rx_byte, 1);
    }
}
```

### MQTT Packet Builder

The STM32 uses no MQTT library, so it needs functions that build the packets. Each one fills a buffer and returns the number of bytes. Notice `encode_remaining_length`: MQTT writes the packet length in 1 to 4 bytes, 7 bits in each.

```c title="mqtt_packet.h"
#ifndef MQTT_PACKET_H
#define MQTT_PACKET_H

#include <stdint.h>

uint16_t mqtt_build_connect(uint8_t *buf, const char *client_id,
                            const char *username, const char *password,
                            const char *will_topic, const char *will_msg,
                            uint16_t keepalive);
uint16_t mqtt_build_publish(uint8_t *buf, const char *topic,
                            const char *payload, uint8_t qos, uint8_t retain);
uint16_t mqtt_build_subscribe(uint8_t *buf, const char *topic, uint8_t qos,
                              uint16_t packet_id);
uint16_t mqtt_build_pingreq(uint8_t *buf);
uint16_t mqtt_build_disconnect(uint8_t *buf);

#endif
```

```c title="mqtt_packet.c"
#include "mqtt_packet.h"
#include <string.h>

static uint16_t encode_remaining_length(uint8_t *buf, uint32_t length)
{
    uint16_t i = 0;
    do {
        uint8_t encoded = length % 128;
        length = length / 128;
        if (length > 0) {
            encoded |= 0x80;
        }
        buf[i++] = encoded;
    } while (length > 0);
    return i;
}

static uint16_t write_utf8_string(uint8_t *buf, const char *str)
{
    uint16_t len = strlen(str);
    buf[0] = (len >> 8) & 0xFF;
    buf[1] = len & 0xFF;
    memcpy(&buf[2], str, len);
    return 2 + len;
}

uint16_t mqtt_build_connect(uint8_t *buf, const char *client_id,
                            const char *username, const char *password,
                            const char *will_topic, const char *will_msg,
                            uint16_t keepalive)
{
    /* Variable header: protocol name, level, flags, keepalive */
    uint8_t var_header[10];
    var_header[0] = 0x00; var_header[1] = 0x04;  /* Protocol name length */
    var_header[2] = 'M'; var_header[3] = 'Q'; var_header[4] = 'T'; var_header[5] = 'T';
    var_header[6] = 0x04;  /* Protocol level (MQTT 3.1.1) */

    uint8_t flags = 0x02;  /* Clean session */
    if (username) flags |= 0x80;
    if (password) flags |= 0x40;
    if (will_topic && will_msg) flags |= 0x04 | 0x08 | 0x20;  /* Will flag + Will QoS 1 + Will retain */

    var_header[7] = flags;
    var_header[8] = (keepalive >> 8) & 0xFF;
    var_header[9] = keepalive & 0xFF;

    /* Calculate payload length */
    uint32_t payload_len = 2 + strlen(client_id);
    if (will_topic && will_msg) {
        payload_len += 2 + strlen(will_topic) + 2 + strlen(will_msg);
    }
    if (username) payload_len += 2 + strlen(username);
    if (password) payload_len += 2 + strlen(password);

    uint32_t remaining = 10 + payload_len;

    /* Fixed header */
    uint16_t pos = 0;
    buf[pos++] = 0x10;  /* CONNECT packet type */
    pos += encode_remaining_length(&buf[pos], remaining);

    /* Variable header */
    memcpy(&buf[pos], var_header, 10);
    pos += 10;

    /* Payload */
    pos += write_utf8_string(&buf[pos], client_id);
    if (will_topic && will_msg) {
        pos += write_utf8_string(&buf[pos], will_topic);
        pos += write_utf8_string(&buf[pos], will_msg);
    }
    if (username) pos += write_utf8_string(&buf[pos], username);
    if (password) pos += write_utf8_string(&buf[pos], password);

    return pos;
}

uint16_t mqtt_build_publish(uint8_t *buf, const char *topic,
                            const char *payload, uint8_t qos, uint8_t retain)
{
    uint16_t topic_len = strlen(topic);
    uint16_t payload_len = strlen(payload);
    uint32_t remaining = 2 + topic_len + payload_len;
    if (qos > 0) remaining += 2;  /* Packet identifier for QoS 1/2 */

    uint16_t pos = 0;
    buf[pos++] = 0x30 | (qos << 1) | retain;  /* PUBLISH fixed header */
    pos += encode_remaining_length(&buf[pos], remaining);

    /* Topic */
    buf[pos++] = (topic_len >> 8) & 0xFF;
    buf[pos++] = topic_len & 0xFF;
    memcpy(&buf[pos], topic, topic_len);
    pos += topic_len;

    /* Packet identifier (QoS 1 or 2 only) */
    if (qos > 0) {
        static uint16_t packet_id = 1;
        buf[pos++] = (packet_id >> 8) & 0xFF;
        buf[pos++] = packet_id & 0xFF;
        packet_id++;
    }

    /* Payload */
    memcpy(&buf[pos], payload, payload_len);
    pos += payload_len;

    return pos;
}

uint16_t mqtt_build_subscribe(uint8_t *buf, const char *topic, uint8_t qos,
                              uint16_t packet_id)
{
    uint16_t topic_len = strlen(topic);
    uint32_t remaining = 2 + 2 + topic_len + 1;  /* packet_id + topic + qos */

    uint16_t pos = 0;
    buf[pos++] = 0x82;  /* SUBSCRIBE fixed header */
    pos += encode_remaining_length(&buf[pos], remaining);

    buf[pos++] = (packet_id >> 8) & 0xFF;
    buf[pos++] = packet_id & 0xFF;

    buf[pos++] = (topic_len >> 8) & 0xFF;
    buf[pos++] = topic_len & 0xFF;
    memcpy(&buf[pos], topic, topic_len);
    pos += topic_len;

    buf[pos++] = qos;

    return pos;
}

uint16_t mqtt_build_pingreq(uint8_t *buf)
{
    buf[0] = 0xC0;  /* PINGREQ */
    buf[1] = 0x00;
    return 2;
}

uint16_t mqtt_build_disconnect(uint8_t *buf)
{
    buf[0] = 0xE0;  /* DISCONNECT */
    buf[1] = 0x00;
    return 2;
}
```

### STM32 Main Application

`mqtt_connect_sequence` runs the steps in order: Wi-Fi, TCP, the MQTT CONNECT packet with the last will, then the subscription to commands. The main loop publishes every 10 seconds and sends a ping at half the keepalive time, so the broker does not declare the device lost. If nothing comes back for 1.5 keepalives (45 s), not even a ping's answer, it reconnects: in transparent mode the ESP-01 does not report a closed connection.

```c title="stm32_mqtt_main.c"
#include "main.h"
#include "esp01_at.h"
#include "mqtt_packet.h"
#include "bme280.h"
#include <stdio.h>
#include <string.h>
#include <time.h>

/* Configuration */
#define WIFI_SSID       "your-ssid"
#define WIFI_PASSWORD   "your-password"
#define BROKER_HOST     "your-broker-ip"
#define BROKER_PORT     1883

#define DEVICE_ID       "stm32-001"
#define TOPIC_TELEMETRY "factory/warehouse-a/stm32/" DEVICE_ID "/telemetry"
#define TOPIC_COMMANDS  "factory/warehouse-a/stm32/" DEVICE_ID "/commands"
#define TOPIC_STATUS    "factory/warehouse-a/stm32/" DEVICE_ID "/status"
#define LWT_MESSAGE     "{\"device_id\":\"" DEVICE_ID "\",\"status\":\"offline\"}"

#define PUBLISH_INTERVAL_MS 10000
#define KEEPALIVE_S         30

static uint8_t mqtt_buf[512];
static bool mqtt_connected = false;
static uint32_t last_rx = 0;      /* tick of the last byte from the broker */
static uint32_t backoff_ms = 1000;
static const uint32_t BACKOFF_MAX_MS = 60000;

void mqtt_connect_sequence(void)
{
    at_result_t res;

    /* Step 1: Connect to Wi-Fi */
    printf("Connecting to Wi-Fi...\r\n");
    res = esp01_wifi_connect(WIFI_SSID, WIFI_PASSWORD);
    if (res != AT_OK) {
        printf("Wi-Fi connection failed\r\n");
        return;
    }
    printf("Wi-Fi connected\r\n");

    /* Step 2: TCP connection to broker */
    printf("Connecting to MQTT broker...\r\n");
    res = esp01_tcp_connect(BROKER_HOST, BROKER_PORT);
    if (res != AT_OK) {
        printf("TCP connection failed\r\n");
        return;
    }
    printf("TCP connected\r\n");

    /* Step 3: Send MQTT CONNECT packet with LWT */
    uint16_t len = mqtt_build_connect(
        mqtt_buf, DEVICE_ID,
        DEVICE_ID,            /* username */
        "your-password",      /* password */
        TOPIC_STATUS,         /* will topic */
        LWT_MESSAGE,          /* will message */
        KEEPALIVE_S
    );
    esp01_send_raw(mqtt_buf, len);

    /* Wait for CONNACK */
    uint8_t resp[32];
    uint16_t resp_len = esp01_recv_raw(resp, sizeof(resp), 5000);
    if (resp_len >= 4 && resp[0] == 0x20 && resp[3] == 0x00) {
        printf("MQTT CONNACK received, connection accepted\r\n");
        mqtt_connected = true;
        backoff_ms = 1000;
        last_rx = HAL_GetTick();

        /* Subscribe to commands */
        len = mqtt_build_subscribe(mqtt_buf, TOPIC_COMMANDS, 1, 1);
        esp01_send_raw(mqtt_buf, len);
        printf("Subscribed to %s\r\n", TOPIC_COMMANDS);
    } else {
        printf("MQTT connection rejected (rc=%d)\r\n",
               resp_len >= 4 ? resp[3] : -1);
        mqtt_connected = false;
    }
}

void mqtt_publish_telemetry(float temperature, float humidity)
{
    if (!mqtt_connected) return;

    char payload[256];
    /* No clock is set here, so "ts" is null and the server stamps the time.
     * HAL_GetTick() / 1000 is time since power-on, not a date: sending it
     * as "ts" would put every reading in January 1970. */
    snprintf(payload, sizeof(payload),
        "{\"device_id\":\"%s\",\"ts\":null,\"temperature\":%.1f,\"humidity\":%.1f}",
        DEVICE_ID, temperature, humidity);

    uint16_t len = mqtt_build_publish(mqtt_buf, TOPIC_TELEMETRY, payload, 0, 0);
    esp01_send_raw(mqtt_buf, len);
    printf("Published: %s\r\n", payload);
}

void mqtt_reconnect(void)
{
    /* Add jitter */
    uint32_t jitter = (HAL_GetTick() % (backoff_ms / 4 + 1));
    uint32_t delay = backoff_ms + jitter;
    printf("Reconnecting in %lu ms\r\n", delay);
    HAL_Delay(delay);

    backoff_ms = (uint32_t)(backoff_ms * 2);
    if (backoff_ms > BACKOFF_MAX_MS) {
        backoff_ms = BACKOFF_MAX_MS;
    }

    esp01_close();
    mqtt_connect_sequence();
}

void mqtt_send_keepalive(void)
{
    if (!mqtt_connected) return;
    uint16_t len = mqtt_build_pingreq(mqtt_buf);
    esp01_send_raw(mqtt_buf, len);
}

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_USART2_UART_Init();
    MX_I2C1_Init();

    esp01_init();
    bme280_init();

    mqtt_connect_sequence();

    uint32_t last_publish = 0;
    uint32_t last_keepalive = 0;

    while (1) {
        uint32_t now = HAL_GetTick();

        /* Publish telemetry every PUBLISH_INTERVAL_MS */
        if (mqtt_connected && (now - last_publish >= PUBLISH_INTERVAL_MS)) {
            float temp = bme280_read_temperature();
            float hum = bme280_read_humidity();
            printf("BME280: temp=%.1f C, hum=%.1f %%\r\n", temp, hum);
            mqtt_publish_telemetry(temp, hum);
            last_publish = now;
        }

        /* Send keepalive ping every keepalive/2 seconds */
        if (mqtt_connected && (now - last_keepalive >= (KEEPALIVE_S * 500))) {
            mqtt_send_keepalive();
            last_keepalive = now;
        }

        /* Check for incoming data (commands) */
        if (mqtt_connected) {
            uint8_t rx[256];
            uint16_t rx_len = esp01_recv_raw(rx, sizeof(rx), 100);
            if (rx_len > 0) {
                last_rx = HAL_GetTick();
                /* Parse MQTT PUBLISH packet from broker */
                printf("Received %u bytes from broker\r\n", rx_len);
                /* In production, parse the MQTT packet header and extract payload */
            }
        }

        /* The broker answers every ping (PINGRESP). Nothing at all for
         * 1.5 keepalives means the link is gone, although the ESP-01
         * reported nothing: reconnect instead of publishing into nothing. */
        if (mqtt_connected &&
            (HAL_GetTick() - last_rx > KEEPALIVE_S * 1500UL)) {
            printf("Broker silent for %d s, reconnecting\r\n", KEEPALIVE_S * 3 / 2);
            mqtt_connected = false;
        }

        /* Reconnect if disconnected */
        if (!mqtt_connected) {
            mqtt_reconnect();
        }
    }
}
```

## Reconnection Strategies

<InArticleAd />


Wi-Fi access points restart, brokers stop for updates, and modems lose signal. A client that retries once and stops is lost; hundreds that retry every second can overload the broker the moment it returns.

### Exponential Backoff with Jitter

The answer is to wait longer after each failure, as you do with a busy telephone number: you try again soon, then after a longer pause. All three clients do this:

<Steps>
1. **Start with a small delay.** The first attempt waits 1 second, so a short interruption is repaired quickly.

2. **Double the delay on each failure:** 2, 4, 8, 16, 32 seconds. This "exponential backoff" gives a broker under maintenance few attempts.

3. **Limit the delay** to 60 seconds, or it would grow to hours.

4. **Add a random part, called jitter,** of 0 to 25% of each delay. Without it, devices that lost the broker at the same instant return at the same instant.
</Steps>

```text
  Attempt   Wait before it   Time since the failure
  ───────   ──────────────   ──────────────────────
     1           1 s                  1 s
     2           2 s                  3 s
     3           4 s                  7 s
     4           8 s                 15 s
     5          16 s                 31 s
     6          32 s                 63 s
     7          60 s  (limit)       123 s

  Each wait also gets a random extra (jitter)
  of up to a quarter of its value.
```

As a formula, with the delays in milliseconds:

```
delay = min(backoff_initial * 2^attempt, backoff_max) + random(0, delay/4)
```

## Message Buffering When Offline

<InArticleAd />


When the connection drops, the device can discard its readings or keep them. Keeping them is worth the code: a gap in the record hides exactly the event you want to study afterwards.

### Buffer Architecture

The buffer is a circular array, like a notebook with a fixed number of lines: when the last line is full, writing continues on the first line over the oldest reading. So it holds the newest readings, and its size sets the outage it covers: 50 entries at one reading every 10 seconds is 500 seconds, a little over 8 minutes. After a reconnect the stored readings are published first, oldest first.

In the listings, notice the store function, which writes one reading and moves the write position, and the flush function, which publishes the stored readings with a pause of 50 ms between them. The ESP32 and Pico versions keep the time of each measurement. The Pico flush publishes with QoS 0, so it is not confirmed.

<Tabs>
<TabItem label="ESP32 (NVS Flash)">
```c title="offline_buffer.c"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"
#include "nvs_flash.h"
#include "esp_log.h"
#include <string.h>
#include <stdio.h>

#define BUFFER_MAX_ENTRIES 100
#define NVS_NAMESPACE      "mqtt_buf"

static const char *TAG = "buffer";

typedef struct {
    float temperature;
    float humidity;
    uint32_t timestamp;
} buffered_reading_t;

static buffered_reading_t buffer[BUFFER_MAX_ENTRIES];
static uint16_t buffer_head = 0;
static uint16_t buffer_count = 0;

void buffer_store(float temp, float hum, uint32_t ts)
{
    buffer[buffer_head].temperature = temp;
    buffer[buffer_head].humidity = hum;
    buffer[buffer_head].timestamp = ts;

    buffer_head = (buffer_head + 1) % BUFFER_MAX_ENTRIES;
    if (buffer_count < BUFFER_MAX_ENTRIES) {
        buffer_count++;
    }

    ESP_LOGI(TAG, "Buffered reading (%u entries stored)", buffer_count);
}

uint16_t buffer_flush(void (*publish_fn)(float, float, uint32_t))
{
    if (buffer_count == 0) return 0;

    uint16_t start;
    if (buffer_count == BUFFER_MAX_ENTRIES) {
        start = buffer_head;  /* Oldest entry is at head when full */
    } else {
        start = 0;
    }

    uint16_t flushed = 0;
    for (uint16_t i = 0; i < buffer_count; i++) {
        uint16_t idx = (start + i) % BUFFER_MAX_ENTRIES;
        publish_fn(buffer[idx].temperature, buffer[idx].humidity,
                   buffer[idx].timestamp);
        flushed++;

        /* Small delay to avoid flooding the broker */
        vTaskDelay(pdMS_TO_TICKS(50));
    }

    ESP_LOGI(TAG, "Flushed %u buffered readings", flushed);
    buffer_count = 0;
    buffer_head = 0;

    return flushed;
}

void buffer_save_to_nvs(void)
{
    nvs_handle_t handle;
    esp_err_t err = nvs_open(NVS_NAMESPACE, NVS_READWRITE, &handle);
    if (err != ESP_OK) return;

    nvs_set_blob(handle, "readings", buffer, sizeof(buffered_reading_t) * buffer_count);
    nvs_set_u16(handle, "count", buffer_count);
    nvs_set_u16(handle, "head", buffer_head);
    nvs_commit(handle);
    nvs_close(handle);

    ESP_LOGI(TAG, "Saved %u readings to NVS", buffer_count);
}

void buffer_load_from_nvs(void)
{
    nvs_handle_t handle;
    esp_err_t err = nvs_open(NVS_NAMESPACE, NVS_READONLY, &handle);
    if (err != ESP_OK) return;

    size_t required_size = sizeof(buffer);
    nvs_get_blob(handle, "readings", buffer, &required_size);
    nvs_get_u16(handle, "count", &buffer_count);
    nvs_get_u16(handle, "head", &buffer_head);
    nvs_close(handle);

    ESP_LOGI(TAG, "Loaded %u readings from NVS", buffer_count);
}
```

```python title="offline_buffer.py"
import json
import time

class OfflineBuffer:
    def __init__(self, max_entries=50, filename="buffer.json"):
        self.max_entries = max_entries
        self.filename = filename
        self.readings = []
        self._load()

    def _load(self):
        """Load buffered readings from flash storage."""
        try:
            with open(self.filename, "r") as f:
                self.readings = json.load(f)
            print(f"Loaded {len(self.readings)} buffered readings")
        except (OSError, ValueError):
            self.readings = []

    def _save(self):
        """Persist buffer to flash."""
        try:
            with open(self.filename, "w") as f:
                json.dump(self.readings, f)
        except OSError as e:
            print(f"Failed to save buffer: {e}")

    def store(self, temperature, humidity):
        """Add a reading to the buffer."""
        entry = {
            "ts": int(time.time()),
            "temperature": round(temperature, 1),
            "humidity": round(humidity, 1)
        }
        self.readings.append(entry)

        # Circular: drop oldest if full
        if len(self.readings) > self.max_entries:
            self.readings.pop(0)

        self._save()
        print(f"Buffered reading ({len(self.readings)} stored)")

    def flush(self, mqtt_client):
        """Publish all buffered readings, then clear the buffer."""
        if not self.readings:
            return

        count = 0
        for entry in self.readings:
            payload = json.dumps({
                "device_id": "pico-001",
                "ts": entry["ts"],
                "temperature": entry["temperature"],
                "humidity": entry["humidity"]
            })
            try:
                mqtt_client.client.publish(
                    "factory/warehouse-a/pico/pico-001/telemetry",
                    payload, qos=0
                )
                count += 1
                time.sleep_ms(50)  # Avoid flooding the broker
            except OSError:
                print(f"Flush interrupted after {count} messages")
                self.readings = self.readings[count:]
                self._save()
                return

        print(f"Flushed {count} buffered readings")
        self.readings = []
        self._save()
```

```c title="offline_buffer_stm32.c"
#include "main.h"
#include <string.h>
#include <stdio.h>

#define BUFFER_MAX_ENTRIES 50

typedef struct {
    float temperature;
    float humidity;
    uint32_t timestamp;
    uint8_t valid;       /* 1 = contains data, 0 = empty */
} buffered_reading_t;

/* RAM buffer (persist to flash/EEPROM for power-cycle survival) */
static buffered_reading_t buffer[BUFFER_MAX_ENTRIES];
static uint16_t buffer_head = 0;
static uint16_t buffer_count = 0;

void buffer_store(float temp, float hum, uint32_t ts)
{
    buffer[buffer_head].temperature = temp;
    buffer[buffer_head].humidity = hum;
    buffer[buffer_head].timestamp = ts;
    buffer[buffer_head].valid = 1;

    buffer_head = (buffer_head + 1) % BUFFER_MAX_ENTRIES;
    if (buffer_count < BUFFER_MAX_ENTRIES) {
        buffer_count++;
    }

    printf("Buffered reading (%u stored)\r\n", buffer_count);
}

uint16_t buffer_flush(void (*publish_fn)(float, float))
{
    if (buffer_count == 0) return 0;

    uint16_t start = (buffer_count == BUFFER_MAX_ENTRIES)
                     ? buffer_head : 0;

    uint16_t flushed = 0;
    for (uint16_t i = 0; i < buffer_count; i++) {
        uint16_t idx = (start + i) % BUFFER_MAX_ENTRIES;
        if (buffer[idx].valid) {
            publish_fn(buffer[idx].temperature, buffer[idx].humidity);
            buffer[idx].valid = 0;
            flushed++;
            HAL_Delay(50);  /* Avoid flooding */
        }
    }

    printf("Flushed %u buffered readings\r\n", flushed);
    buffer_count = 0;
    buffer_head = 0;
    return flushed;
}
```

### Testing Disconnection and Reconnection

To verify the reconnection and buffering logic:

<Steps>
1. **Unplug the Wi-Fi router** (or disable the Wi-Fi access point) for 30 seconds. Watch the serial monitors on each device. You should see backoff messages with increasing delays.

2. **Restore Wi-Fi.** Each device should reconnect automatically. The ESP32 and Pico should flush their buffered readings, and you will see a burst of messages in `mosquitto_sub` with timestamps from the offline period.

3. **Stop and restart Mosquitto.** Run `sudo systemctl stop mosquitto`, wait 20 seconds, then `sudo systemctl start mosquitto`. The devices should reconnect and publish their online status. No LWT appears in this test, because the broker is the one that publishes the LWT and it was not running. To see the LWT (status: offline), remove power from one device and wait about 45 seconds: the broker gives up on a silent client after 1.5 times the 30-second keepalive.

4. **Send a command.** Publish a command to change the publish interval:
   ```bash
   mosquitto_pub -h localhost -p 1883 \
     -u "admin" -P "admin-password" \
     -t "factory/warehouse-a/esp32/esp32-001/commands" \
     -m '{"command":"set_interval","value":30}'
   ```
   The ESP32 serial monitor should show that it received the command and set the interval to 30 seconds, and the readings in `mosquitto_sub` should now come 30 seconds apart. Send `"value":0` as well: the device must refuse it and keep 30, because an interval of 0 would publish without pause.
</Steps>

    ESP32 in C, RPi Pico W in MicroPython, STM32 through an ESP-01 or Ethernet. All send the same MQTT and JSON, so the broker cannot tell which board sent the data.
  </Card>

  <Card title="Resilient Connections" icon="setting">
    A growing delay with a random part stops all devices from returning at the same instant. A buffer keeps the newest readings during an outage, up to its size. The last will tells subscribers when a device has gone.
  </Card>

## Exercises

<InArticleAd />


**Exercise 1: Add a third sensor type.** Connect a light sensor (BH1750 or LDR with ADC) to one of the boards. Add a `"light_lux"` field to the JSON payload and check that it appears in the `mosquitto_sub` output.

**Exercise 2: Acknowledge commands.** When a device receives a command such as `set_interval`, let it publish an answer on a new `ack` subtopic (for example `factory/warehouse-a/esp32/esp32-001/ack`) with the command name, the new value and a success or failure status. Do this on all three boards.

**Exercise 3: Test the offline buffer.** Disconnect the Wi-Fi for 5 minutes while all three devices run. Reconnect, count the readings that each device sends from its buffer, and explain any that are missing. Try flush delays of 10 ms, 50 ms and 200 ms and observe whether the broker drops messages.

**Exercise 4: Two destinations.** Change one client so that it connects to your own Mosquitto broker and to the SiliconWit.io MQTT endpoint at the same time, with two client instances that reconnect independently. Record the extra RAM and processor use.
